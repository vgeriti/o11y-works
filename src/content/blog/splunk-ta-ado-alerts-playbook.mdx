## Overview

Repeated alert triggers during high-severity outages lead to ticket fatigue and duplicated Azure DevOps Work Items. The `TA_ado_alerts` Splunk Add-On solves this using native KVStore deduplication.

---

## ⚡ Alert Action Configuration

Use the following SPL query in your Splunk Scheduled Search:

```spl
# Splunk SPL Query for State-Aware ADO Alert Triggers
index=main sourcetype="kube:logs" severity="CRITICAL"
| stats count by service_name, cluster_name, error_reason
| eval ado_project = "SOC-Incident-Response"
| eval ado_area_path = "CyberSecurity\\Tier-1"
```
