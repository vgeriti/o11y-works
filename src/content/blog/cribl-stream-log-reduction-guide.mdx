## Overview

High-volume debug logs account for over 40% of Splunk license consumption. Using Cribl Stream, you can scrub non-essential headers and drop redundant stack traces before indexing.

---

## 🌀 Cribl Pipeline Expression

```json
{
  "id": "log-reduction-pipeline",
  "async": false,
  "functions": [
    {
      "id": "eval",
      "filter": "sourcetype === 'app:debug'",
      "conf": {
        "add": [
          { "name": "_raw", "value": "__e._raw.replace(/timestamp=\\d+\\s+/, '')" }
        ],
        "remove": ["debug_stacktrace", "internal_thread_id"]
      }
    }
  ]
}
```

## 🗄️ ClickHouse Verification Query

Verify log volume reduction after Cribl processing:

```sql
SELECT 
    date_trunc('hour', timestamp) AS hour_bucket,
    sum(length(_raw)) / 1024 / 1024 / 1024 AS volume_gb
FROM logs_analytics.processed_logs
WHERE timestamp >= now() - INTERVAL 24 HOUR
GROUP BY 1
ORDER BY 1 DESC;
```
